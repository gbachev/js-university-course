# 2. First Steps

The tools we work with: Node.js and an editor, how the web works with HTTP, and npm and nvm for packages and Node.js versions.

1. Environment Setup (no code) - installing Node.js and Visual Studio Code, and getting this repository
2. [HTTP: How the Web Works](http) - requests, responses, status codes and headers, and a tiny Node.js server
3. A First Look at npm and nvm (no code) - what npm, `package.json` and the lock file are, running this repository's tests with `npm test`, and switching Node.js versions with nvm
