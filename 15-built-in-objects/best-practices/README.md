# Best Practices

Code for the lecture *Best Practices* (section 15, Built-in Objects) of the JavaScript course at gbachev.com.

## Examples
- `examples/01-check-parsed-json.js` - checking the shape of parsed JSON, with a safe default
- `examples/02-parse-only-iso.js` - a date in another format built from its parts instead of guessed
- `examples/03-return-a-new-date.js` - a helper that returns a new date and leaves the caller's date as it was
- `examples/04-string-methods.js` - `startsWith()` and `includes()` instead of a regex for fixed text
- `examples/05-compare-values.js` - a formatted price is not equal to the text we type, until we normalize its spaces

Run one with `node 15-built-in-objects/best-practices/examples/01-check-parsed-json.js` from the repository folder.
