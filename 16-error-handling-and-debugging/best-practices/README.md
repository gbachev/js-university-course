# Best Practices

Code for the lecture *Best Practices* (section 16, Error Handling and Debugging) of the JavaScript course at gbachev.com.

## Examples
- `examples/01-validate-at-the-boundary.js` - a `NaN` that travels on, and a `RangeError` where the bad input enters
- `examples/02-no-empty-catch.js` - an empty `catch`, and one that logs the error and tells the user
- `examples/03-one-small-hierarchy.js` - checking the type with `instanceof` instead of the text of the message

Run one with `node 16-error-handling-and-debugging/best-practices/examples/01-validate-at-the-boundary.js` from the repository folder.
