# What is JavaScript

Code for the lecture *What is JavaScript* (section 3, JavaScript Foundations) of the JavaScript course at gbachev.com.

## Examples
- `examples/01-inline-script.html` - JavaScript written straight inside a `script` tag
- `examples/02-external-script.html` - a page that loads its JavaScript from `app.js` next to it
- `examples/03-console-methods.js` - `console.log()`, `console.warn()` and `console.error()`
- `examples/04-case-sensitivity.js` - `a` and `A` are two different variables
- `examples/05-wrong-capital-letter.js` - `Console.log` with a capital C is a `ReferenceError`
- `examples/06-semicolons.js` - statements with and without semicolons, and several on one line
- `examples/07-asi-pitfall.js` - a line that starts with `(` continues the line before it

The two pages run in the browser: open the HTML file (double-click it, or use the Live Server extension in VS Code) and look at the console in DevTools. The `.js` examples run in Node too, with `node 03-javascript-foundations/intro/examples/03-console-methods.js` from the repository folder, or paste their lines into the browser console.
