# Types in JavaScript

Code for the lecture *Types in JavaScript* (section 6, Types) of the JavaScript course at gbachev.com.

## Examples
- `examples/01-dynamic-typing.js` - one variable holds a string, then a number, then a boolean, and `typeof` shows each type

Run it with `node 06-types/types/examples/01-dynamic-typing.js` from the repository folder.

## Tasks
1. **What type is it?** (`tasks/01-describe-value.js`) - describe a value together with the type `typeof` gives for it
2. **Did the type change?** (`tasks/02-type-changed.js`) - tell whether a value changed its type after an edit

Run the tests with `npm test -- 06-types/types`. They fail until the task is solved. Compare with `solutions/` after you try.
