# Best Practices

Code for the lecture *Best Practices* (section 5, Control Flow) of the JavaScript course at gbachev.com.

## Examples
- `examples/01-choose-the-loop.js` - `for` for a range of numbers, `for...of` when we only need the values
- `examples/02-filter-instead-of-splice.js` - `filter` instead of removing items while we loop
- `examples/03-name-the-condition.js` - a long condition moved into a well-named constant
- `examples/04-switch-for-many-values.js` - `switch` instead of a long `if ... else if` chain
- `examples/05-guard-clauses.js` - a guard clause instead of nested `if` statements
- `examples/06-switch-default.js` - a `default` case for the values we did not expect

Run one with `node 05-control-flow/best-practices/examples/01-choose-the-loop.js` from the repository folder.
