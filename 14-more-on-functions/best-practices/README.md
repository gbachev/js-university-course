# Best Practices

Code for the lecture *Best Practices* (section 14, More on Functions) of the JavaScript course at gbachev.com.

## Examples
- `examples/01-keep-the-object.js` - an arrow callback keeps the object of the method
- `examples/02-base-case-it-cannot-miss.js` - a base case that negative input cannot skip
- `examples/03-choose-the-arguments.js` - wrap `parseInt` in an arrow function instead of `map(parseInt)`
- `examples/04-return-new-data.js` - return new objects instead of changing the caller's items

Run one with `node 14-more-on-functions/best-practices/examples/01-keep-the-object.js` from the repository folder.
