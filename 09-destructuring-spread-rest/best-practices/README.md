# Best Practices

Code for the lecture *Best Practices* (section 9, Destructuring, Spread and Rest) of the JavaScript course at gbachev.com.

## Examples
- `examples/01-parameter-destructuring.js` - destructure the properties a function needs in its parameters
- `examples/02-safe-defaults.js` - default values, and `{}` when the whole object is missing
- `examples/03-destructure-in-steps.js` - a deep structure destructured in two steps
- `examples/04-spread-order.js` - merge objects from the most general source to the most specific

Run one with `node 09-destructuring-spread-rest/best-practices/examples/01-parameter-destructuring.js` from the repository folder.
