# Operator Precedence

Code for the lecture *Operator Precedence* (section 4, Operators) of the JavaScript course at gbachev.com.

## Examples
- `examples/01-exam-task.js` - the exam task from the lecture, to check our answer

Run it with `node 04-operators/precedence/examples/01-exam-task.js` from the repository folder.

## Tasks
1. **The average rating** (`tasks/01-average-rating.js`) - fix an average that divides only the last rating
2. **The receipt line** (`tasks/02-receipt-line.js`) - fix a total that is joined as text instead of added
3. **The exam task** (`tasks/03-exam-task.js`) - work out the exam task from the lecture on paper

Run the tests with `npm test -- 04-operators/precedence`. They fail until the task is solved. Compare with `solutions/` after you try.
