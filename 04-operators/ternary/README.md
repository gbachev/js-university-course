# Ternary Operator

Code for the lecture *Ternary Operator* (section 4, Operators) of the JavaScript course at gbachev.com.

## Examples
- `examples/01-pass-or-try-again.js` - choose between two values based on a score
- `examples/02-if-else-or-ternary.js` - the same assignment with `if ... else` and with `? :`
- `examples/03-chained-ternary.js` - a chain of ternary operators and the `if ... else if` chain it replaces

Run one with `node 04-operators/ternary/examples/01-pass-or-try-again.js` from the repository folder.

## Tasks
1. **Pass or try again** (`tasks/01-exam-status.js`) - return the exam status with one ternary operator
2. **One item, two items** (`tasks/02-items-label.js`) - write the cart label in the singular or the plural
3. **Grade the score** (`tasks/03-grade-the-score.js`) - turn a score into a letter grade with a chain of ternary operators

Run the tests with `npm test -- 04-operators/ternary`. They fail until the task is solved. Compare with `solutions/` after you try.
