# Arithmetic Operators

Code for the lecture *Arithmetic Operators* (section 4, Operators) of the JavaScript course at gbachev.com.

## Examples
- `examples/01-basic-arithmetic.js` - `+`, `-`, `*`, `/` and `%`
- `examples/02-increment-decrement.js` - `++` and `--` as prefix and as postfix
- `examples/03-unary-negation-and-plus.js` - unary `-`, and unary `+` that converts to a number
- `examples/04-exponentiation.js` - `**`, also with a negative exponent

Run one with `node 04-operators/arithmetic/examples/01-basic-arithmetic.js` from the repository folder.

## Tasks
1. **Add the form quantities** (`tasks/01-add-form-quantities.js`) - turn two text values into numbers and add them
2. **Pack the boxes** (`tasks/02-pack-the-boxes.js`) - count the full boxes and the leftover items with `%`
3. **The next ticket number** (`tasks/03-next-ticket-number.js`) - fix a counter that returns the old number

Run the tests with `npm test -- 04-operators/arithmetic`. They fail until the task is solved. Compare with `solutions/` after you try.
