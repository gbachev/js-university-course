# Best Practices

Code for the lecture *Best Practices* (section 22, Performance and Memory) of the JavaScript course at gbachev.com.

## Examples
- `examples/01-clean-up-what-we-start.html` - one function stops the listener, the timer and the observer a panel started (with `01-clean-up-what-we-start.js`)
- `examples/02-debounce-input.html` - one search per key against one debounced search (with `02-debounce-input.js`)
- `examples/03-lazy-below-the-fold.html` - an eager LCP image and a lazy cover, both with a size

The examples run in the browser. Run `npm run serve` from the repository folder, open a page from the address it prints and look at the console or the Network panel.
