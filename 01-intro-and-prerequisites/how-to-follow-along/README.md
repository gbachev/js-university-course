# How to Follow Along

Code for the lecture *How to Follow Along* (section 1, Intro & Prerequisites) of the JavaScript course at gbachev.com.

## Examples
- `examples/01-browser-console.js` - a first snippet to type into the browser console
- `examples/02-hello.js` - the `hello.js` file we run with Node.js
- `examples/03-predict-the-output.js` - two lines to predict before we run them

Run one with `node 01-intro-and-prerequisites/how-to-follow-along/examples/02-hello.js` from the repository folder. We install Node.js in the next lecture, *Environment setup*. Until then, the first and the last example also run in the browser console: copy the lines, paste them and press Enter.
